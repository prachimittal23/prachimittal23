## 🧩 Featured Projects

### 🏗️ TrackIT - Enterprise Project Management Platform
> Replaced a $230K/year third-party tool at American Tire Distributors

Designed and built an OpenProject-based platform on Google Cloud, end-to-end. Pitched the migration, owned architecture, integrated Okta SSO via SAML, built the Python/FastAPI service wrapping OpenProject's REST API, and developed the scheduled extract pipeline that pushes data to our finance system via GCS and Cloud Scheduler.

**Impact:** $230K/year saved · Used daily by every PM and resource manager  
**Stack:** Python, FastAPI, GKE, GCS, Cloud Scheduler, Okta, SAML, Workload Identity, PostgreSQL

### 🔎 AutoAssist AI - RAG Chatbot
> Real-time query resolution over dynamic datasets

Built a retrieval-augmented chatbot integrating vector search and LLMs. The model gets the right context for each query rather than relying on training data alone, so it stays grounded as the underlying data changes. Designed the backend APIs and ingestion pipelines.

**Stack:** Python, LangChain, Vector Search, OpenAI API, FAISS

### ⚙️ Word Document Conversion Microservice
> 45 min → under 1 min (~95% reduction)

**Impact:** 95% time reduction · Eliminated manual conversion effort entirely  
**Stack:** Python, GKE, GCS, Workload Identity, IAM, async/await
